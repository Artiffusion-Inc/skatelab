# Blog & Docs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use subagent-driven-development (recommended) or executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить `docs.skatelab.ru` (user docs + закрытые dev/agent docs) и `blog.skatelab.ru` поверх существующего Next.js frontend через Fumadocs и host-based middleware.

**Architecture:** Один Next.js app. Caddy роутит два subdomain на `frontend:3000`. Middleware хост-детектит и rewrite'ит на route-группы `(docs)`/`(blog)` с path-based локалью `/ru`/`/en`. Контент — MDX в репо (`frontend/content/`). Закрытый `internal/` раздел — page-level gate через `STAFF_EMAILS` env на backend + флаг `isStaff` в `/v1/users/me`, `force-dynamic` чтобы MDX не утёк как static.

**Tech Stack:** Next.js 16 (app router, standalone), Fumadocs (`fumadocs-ui`, `fumadocs-core`, `fumadocs-mdx`), next-intl (path-based для docs/blog, cookie для app), Tailwind v4 (`@import "tailwindcss"`), Litestar backend, Pydantic BaseSettings, vitest (frontend), pytest (backend).

## Global Constraints

- Backend — **Litestar**, не FastAPI (вопреки root CLAUDE.md). Routes: `@get`/`@patch`/`@post` из `litestar`, `Controller` base.
- Frontend — Next.js 16, **standalone** билд (`output: "standalone"` в `next.config.ts`), turbopack.
- Tailwind v4: CSS-first конфиг (`@import "tailwindcss"` в `globals.css`), нет `tailwind.config.js`. Плагины через `@plugin` в CSS или postcss. Fumadocs интегрируется через `@fumadocs/tailwind` import в `globals.css`.
- i18n: `messages/ru.json` + `messages/en.json` (next-intl). Основной app — cookie-based (`NEXT_LOCALE`, allow-list ru/en). docs/blog — path-based `[locale]` segment.
- Auth cookie: `sk_session` (JWT). `/v1/users/me` возвращает `UserResponse`.
- Env-префикс в `backend/app/config.py`: pattern `class XConfig(BaseSettings): ... class Config: env_prefix = "X_"`.
- Запуск frontend тестов: `cd frontend && bun run test` (vitest), `bun run typecheck` (tsc), `bun run lint` (biome).
- Запуск backend тестов: `uv run pytest <path>`.
- Контент — MDX в `frontend/content/`, публикация через git PR. Ноль CMS, ноль БД-контента.
- Закрытые dev docs: `STAFF_EMAILS` env (server-side, не `NEXT_PUBLIC`). MVP-allowlist; upgrade path = `User.is_staff` колонка + миграция (Phase 2).
- `/internal/*` страницы обязаны `export const dynamic = 'force-dynamic'`.
- Все коммиты по convention: `<type>(<scope>): <desc>`. Скопы: `frontend`, `backend`, `docs`, `infra`.

```ts
export const LOCALES = ['ru', 'en'] as const
export type Locale = (typeof LOCALES)[number]
export const DEFAULT_LOCALE: Locale = 'ru'

export function isLocale(v: string | undefined): v is Locale {
  return !!v && (LOCALES as readonly string[]).includes(v)
}

export function resolveLocale(seg: string | undefined): Locale {
  return isLocale(seg) ? seg : DEFAULT_LOCALE
}
```

- [ ] **Step 4: Implement host-based rewrite**

`frontend/src/middleware.ts`:
```ts
import { postHogMiddleware } from '@posthog/next'
import { NextResponse, type NextRequest } from 'next/server'

const postHog = postHogMiddleware({ proxy: true })

const DOCS_HOST = 'docs.skatelab.ru'
const BLOG_HOST = 'blog.skatelab.ru'

export default function middleware(req: NextRequest) {
  const host = req.headers.get('host') ?? ''
  if (host === DOCS_HOST) {
    const url = req.nextUrl.clone()
    url.pathname = `/docs${url.pathname}`
    return NextResponse.rewrite(url)
  }
  if (host === BLOG_HOST) {
    const url = req.nextUrl.clone()
    url.pathname = `/blog${url.pathname}`
    return NextResponse.rewrite(url)
  }
  return postHog(req)
}

export const config = {
  matcher: ['/((?!_next/static|_next/image|favicon.ico|api).*)'],
}
```

Примечание: rewrite на `/docs` маппит на route-группу `(docs)` — route-группы в скобках не входят в URL, поэтому файл `app/(docs)/[locale]/...` обслуживает `/docs/...` после rewrite. Сверить поведение в Step 6 (dev-сервер).

`frontend/src/lib/staff.ts`:
```ts
import { cookies } from 'next/headers'
import { redirect } from 'next/navigation'

const API_URL = process.env.NEXT_PUBLIC_API_URL ?? 'http://localhost:8000'

export async function getStaffStatus(): Promise<{ isStaff: boolean }> {
  const store = await cookies()
  const token = store.get('sk_session')?.value
  if (!token) return { isStaff: false }
  try {
    const res = await fetch(`${API_URL}/v1/users/me`, {
      headers: { Authorization: `Bearer ${token}` },
      cache: 'no-store',
    })
    if (!res.ok) return { isStaff: false }
    const data = (await res.json()) as { is_staff?: boolean }
    return { isStaff: !!data.is_staff }
  } catch {
    return { isStaff: false }
  }
}

export async function requireStaff(nextUrl: string): Promise<void> {
  const { isStaff } = await getStaffStatus()
  if (!isStaff) {
    redirect(`/login?next=${encodeURIComponent(nextUrl)}`)
  }
}
```

```ts
import type { MetadataRoute } from 'next'
import { docs } from '@/.source'
import { LOCALES } from '@/lib/docs-i18n'

export default function sitemap(): MetadataRoute.Sitemap {
  const entries: MetadataRoute.Sitemap = []
  for (const loc of LOCALES) {
    for (const page of docs.getPages(loc)) {
      // исключаем internal
      if (page.url.includes('/internal/')) continue
      entries.push({
        url: `https://docs.skatelab.ru/${loc}${page.url}`,
        alternates: {
          languages: Object.fromEntries(
            LOCALES.map((l) => [l, `https://docs.skatelab.ru/${l}${page.url}`])
          ),
        },
      })
    }
  }
  return entries
}
```
