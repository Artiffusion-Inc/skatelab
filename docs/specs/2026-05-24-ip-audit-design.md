# IP Audit & Compliance Strategy

> Дата: 2026-05-24
> Статус: Draft

## Проблема

4 ключевых ML-компонента имеют лицензионные ограничения для коммерческого использования:

| Компонент | Лицензия | Ограничение | Где используется |
|-----------|----------|-------------|------------------|
| YOLOv8n (веса .onnx) | AGPL-3.0 | Сеть = раскрыть весь код | `person_detector.py`, `gpu_server/server.py` |
| MogaNet-B-ap2d | CC BY-NC (AthletePose3D weights) | Коммерция запрещена | `moganet_batch.py` (основной пайплайн) |
| MotionAGFormer-S-ap3d | CC BY-NC (AP3D) + Academic (H3.6M) | Коммерция запрещена | `onnx_extractor.py`, `skeletal_identity.py` |
| TCPFormer-ap3d | CC BY-NC (AP3D) + Academic (H3.6M) | Коммерция запрещена | `tcpformer_extractor.py` |

Остальные компоненты (deep-sort-realtime MIT, Sports2D BSD, scipy BSD, numba BSD, ONNX Runtime MIT) — перmissive, проблем нет.

## Юридический анализ

### Российская юрисдикция (2025-2026)

**Практический риск для российского стартапа на данном этапе — минимальный:**

1. **AGPL ни разу не применялась в российских судах.** Единственные дела по открытым лицензиям — CC BY (2 дела, российские правообладатели). Никаких дел с иностранными NC-лицензиями.

2. **Исполнение иностранных решений в РФ практически невозможно.** Россия не признаёт решения судов США/ЕС. Закон №171-ФЗ позволяет анти-сьют инъюнкции. Декрет №299 — 0% компенсация за патенты из "недружественных" стран.

3. **Веса моделей — не "программа для ЭВМ" (ст. 1261 ГК РФ).** Статья покрывает исходный код, не числовые параметры. Защитить чужие веса по авторскому праву в РФ крайне сложно (Мельникова Е.Н., Zakon №6/2023).

4. **Статья 1286.1 ГК РФ** признаёт открытые лицензии, но AGPL и CC BY-NC не тестировались в судах. Квалификация NC-ограничения российским судом — открытый вопрос.

### Реальный риск — not litigation, а M&A/due diligence

- VC due diligence вскроет AGPL/NC нарушения → убьёт сделку
- Anthropic прецедент: $1.5B за пиратство (способ приобретения, не обучение)
- Thomson Reuters v. Ross: использование copyrighted данных для конкурирующего продукта = не fair use

### Дистилляция: серая зона, самый безопасный подход

- AGPL покрывает распространение кода, не выходы модели
- CC BY-NC формально покрывает "exercise of Licensed Rights", но выходы модели не являются объектом авторского права (US Copyright Office)
- Нет судебных прецедентов по дистилляции ML-моделей
- **Наименее рискованный подход:** использовать модели для генерации псевдо-лейблов → обучать свою модель на этих лейблах

## Стратегия: риск-ориентированный подход

**Принцип:** Качество продукта приоритет. Замена критических ML-компонентов на permisive-альтернативы = потеря точности на фигурном катании. Компромисс недопустим — пользователь платит за точность метрик.

**Риск-профиль для российского рынка (2026):**
- Судебный иск: ~0% (нет прецедентов AGPL/NC в РФ, нет юрисдикции для иностранных истцов)
- Исполнение решений: практически невозможно (Декрет №299, Закон №171-ФЗ)
- VC due diligence: риск возникает только при привлечении западных инвестиций

**Решение:** Использовать все текущие модели как есть. Управлять риском через структуру кода и документацию, не через замену компонентов.

### Немедленные действия (Фаза 1)

1. **Перенести `ultralytics` в dev-dependencies.**
   - Продакшен-код уже не импортирует `ultralytics` (`person_detector.py` — чистый ONNX)
   - `ultralytics` нужен только для обучения (`train_yolo26_pose.py`)
   - Это устраняет AGPL copyleft на Python-уровне в проде
   - Веса .onnx остаются под AGPL, но copyleft на веса — не тестировался в судах

2. **Все модели остаются в проде без изменений.**
   - YOLOv8n — детекция персон (AGPL-3.0 веса)
   - MogaNet-B-ap2d — 2D pose estimation (CC BY-NC от AP3D)
   - MotionAGFormer-S-ap3d — 3D подъём (CC BY-NC + Academic)
   - TCPFormer-ap3d — 3D подъём альтернатива (CC BY-NC + Academic)
   - **Обоснование:** Замена = просадка точности. Риск для РФ минимален.

3. **Добавить NOTICE.md с полным перечислением лицензий.**
   - Честно указать все компоненты, лицензии, атрибуции
   - Для AthletePose3D: указать CC BY-NC + citation
   - Для YOLOv8n: указать AGPL-3.0 + ссылка на Ultralytics
   - Для Human3.6M: указать academic-use only (через pretrained weights MotionAGFormer/TCPFormer)

4. **Структура IP-документации.**
   - `NOTICE.md` — краткий список для разработчиков
   - `docs/specs/2026-05-24-ip-audit-design.md` — полный аудит
   - В публичных материалах: не скрывать использование, честно указывать лицензии

### Среднесрочный план (Фаза 2, 6–12 месяцев): дистилляция

**Цель:** Постепенно создать коммерчески чистые модели, не теряя качество.

**Подход:** Использовать текущие модели для генерации псевдо-лейблов → обучить свои модели на этих лейблах + COCO + собственные данные.

1. **Собрать собственный датасет фигурного катания.**
   - MCFS, SkatingVerse, публичные трансляции соревнований
   - Проверить лицензии MCFS, SkatingVerse, FSC
   - Цель: 50-100 видео с разметкой

2. **Дистилляция MogaNet-B.**
   - MogaNet-B-ap2d генерирует псевдо-лейблы на собственном датасете
   - Обучить MogaNet-B-coco (Apache-2.0) на псевдо-лейблах + COCO
   - Результат: MogaNet-B-skate — коммерчески чистая, точность ~ap2d
   - Юридически: выходы модели ≠ производное произведение (нет прецедентов обратного)

3. **YOLOv8n → YOLOX-nano или RF-DETR (при необходимости).**
   - Только если Ultralytics потребует Enterprise License
   - YOLOX: Apache-2.0, RF-DETR: Apache-2.0
   - Детекция персон — проще pose estimation, замена менее болезненна

4. **3D-подъём: коммерческая лицензия или переобучение.**
   - Написать авторам AthletePose3D (Calvin Yeung, calvinyeungck) с запросом коммерческой лицензии
   - Университеты часто дают коммерческие лицензии за $1K-10K
   - Альтернатива: переобучить MotionAGFormer на permisive данных

### Долгосрочный план (Фаза 3, 12+ месяцев): полная чистота

**Триггер:** международное расширение, западные инвестиции, M&A.

1. MogaNet-B-skate заменяет ap2d полностью
2. YOLOX/RF-DETR заменяет YOLOv8n (если ещё не сделано)
3. 3D-подъём: permisive модель или коммерческая лицензия AP3D/H3.6M
4. Удалить NC-licensed веса из репо и прод-пайплайна
5. Полный IP-аудит для due diligence: чистый chain of custody

## Альтернативы (если дистилляция не сработает)

1. **Ultralytics Enterprise License** — ~$500-2000/год, решает AGPL полностью
2. **Коммерческая лицензия AthletePose3D** — написать авторам (Calvin Yeung, calvinyeungck), запросить коммерческую лицензию. Университеты часто дают коммерческие лицензии за разумные деньги ($1K-10K).
3. **Коммерческая лицензия Human3.6M** — контакт через сайт IMAR, обычно $5K-50K/год для коммерческих организаций
4. **Замена MogaNet на RTMPose** (Apache-2.0, MMPose) — другая архитектура, но permisive

## Сноски и источники

- Jacobsen v. Katzer (2008) — открытые лицензии = авторское право, enforceable
- Artifex v. Hancom (2017) — GPL enforceable как контракт
- Neo4j v. PureThink (2021-2025) — AGPL enforcement precedent
- Thomson Reuters v. Ross Intelligence (2025) — использование copyrighted данных для конкурирующего продукта = не fair use
- Bartz v. Anthropic (2025) — $1.5B settlement за пиратство (acquisition method), не за обучение
- ГК РФ ч.4 ст. 1286.1 — открытые лицензии
- ГК РФ ч.4 ст. 1261 — программа для ЭВМ
- ГК РФ ч.4 ст. 1465 — ноу-хау
- Декрет №299 (март 2022) — 0% компенсация за патенты из "недружественных" стран
- Закон №171-ФЗ — анти-сьют инъюнкции
- Мельникова Е.Н. "Правовая квалификация модели машинного обучения", Zakon №6/2023
