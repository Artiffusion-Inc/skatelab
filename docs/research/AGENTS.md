# Research Documentation

`RESEARCH.md` is canonical index for research files.

## Rules

- Add every new or removed research document to `RESEARCH.md`.
- Name new research `RESEARCH_<TOPIC>_<YYYY-MM-DD>.md` or `RESEARCH_SUMMARY_<YYYY-MM-DD>.md`.
- Include date, sources, status, summary, findings, and project implications.
- Separate evidence from interpretation; cite primary sources when available.
- Preserve rejected paths with reason and status instead of deleting history.
- Put executable experiments in `experiments/` or `ml/`, never here.
- Use actual research date, not file creation date.
