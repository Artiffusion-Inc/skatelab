# Product Positioning & Messaging

> **Актуально:** Hardware-first модель (IMU-трекеры). SaaS — дополнение.
> **Источник:** Данные Алисы из CustDev. Последнее обновление: 2026-05-11.

## Positioning Statement

**SkateLab** — система, которая превращает технику фигуриста в наглядные данные.

Если ты тренируешься без трекеров — ты проигрываешь тем, кто их использует.

## Value Proposition (CustDev-validated)

| Что важно клиенту | Как IMU-трекеры решают |
|-------------------|---------------------|
| Ускорение прогресса | Точные метрики (IMU + AI) → понимание ошибок → быстрое исправление |
| Уверенность в технике | Данные вместо "кажется" |
| Экономия времени | 12-секундный анализ вместо 10–20 минут ручного разбора |
| Меньше споров тренер ↔ спортсмен | Объективные данные — нет субъективных споров |

## Key Insight from CustDev

**Тренеры НЕ покупают «технологию». Покупают:**
- Экономию времени
- Меньше споров
- Быстрый прогресс учеников

**Спортсмены покупают:**
- Ускорение прогресса
- Снижение стоимости ошибок

## Key Trigger (Must-Have, not Nice-to-Have)

**Текущее:** "круто, но не необходимо"
**Нужно:** "Без этого ты проигрываешь"

**Формула срабатывания:**
1. Данные быстрее, чем визуальный анализ
2. Данные понятны тренеру без интерпретации
3. Видно ускорение прогресса спортсмена

> **Критический риск:** Если продукт не показывает "ускорение прогресса" в первые недели — не будет принят рынком.

## Pricing Positioning

### Hardware (IMU-трекеры)

| Tier | Цена (₽) | Сегмент |
|------|---------|---------|
| Individual (2 IMU + крепление + зарядка) | **15 500** | Тренеры / спортсмены |
| Pro (проф клубы) | 30 000 | Академии |
| Coach (3–5 sets) | 80 000–150 000 | Pro coaches |
| Academy (групповой + планшет) | 250 000–500 000 | Schools |

**Sweet spot:** 10–30K ₽ — не дёшево → серьёзно, не дорого → не B2B lab.

### SaaS Subscription (Secondary)

| Tier | Цена/мес | Сегмент |
|------|----------|---------|
| Entry | 490 ₽ | Спортсмены |
| Pro | 990 ₽ | Продвинутые |
| Coach | 1 500–3 500 ₽ | Тренеры |

**Business logic:** Hardware = основной продукт (маржа ~67%). Subscription = дополнительный поток.

**LTV/CAC:** ~6.3x при контент-маркетинге (CAC 2 500 ₽). ∞ при продажах через founder network (Алиса).
