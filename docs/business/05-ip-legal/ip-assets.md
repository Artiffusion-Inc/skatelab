### Critical Legislative Changes (2024–2025)

| Закон | Дата | Что изменилось |
|-------|------|----------------|
| ФЗ № 233-ФЗ | 1 сентября 2025 | **Запрет** включать согласие на обработку ПДн в состав других документов. Нельзя «спрятать» в договор/оферту. Отдельный чекбокс обязателен. |
| ФЗ № 420-ФЗ | 30 ноября 2024 | Усилена ответственность по КоАП за нарушения в обработке ПДн. |
| Роскомнадзор | 30 мая 2025 | Уведомление о ПДн нужно обновить до этой даты. Типичные ошибки: кто подписывает за несовершеннолетних. |

**Критично:**
- Нельзя ограничивать доступ к услугам, если пользователь отказался предоставлять ПДн
- Биометрические данные (скелетон) → **отдельное согласие**, нельзя объединять с обычным
- Поведенческие данные (метрики катания) → требуют отдельного согласия с 2025

| Consent — Personal Data (Согласие на обработку ПДн) | ❌ Не создан | Отдельное согласие на обработку персональных данных | Чекбокс при вводе данных |
| Consent — Anonymized Data (Согласие на обработку анонимизированных) | ❌ Не создан | Отдельное согласие на обработку анонимизированных/биометрических данных | Чекбокс при вводе данных |

## Data Privacy

| Регламент | Требования | Статус |
|-----------|-----------|--------|
| 152-ФЗ (Россия) | Персональные данные → серверы в РФ | ❌ Нет (R2/CF — США/EU) |
| GDPR (EU) | Consent, data portability, right to be forgotten | ❌ Нет |
| COPPA (дети) | Parental consent для <13 | ❓ Нужен (родители — сегмент B2) |

> **Критичный риск:** 152-ФЗ требует хранение персональных данных россиян на серверах в РФ. R2/Cloudflare — США/EU. Решение: российский хостинг для БД + R2 для медиа (персональные данные ≠ видео).

## Competitive IP Position

**Moat:** Не патенты, а:
1. **Data network effect** — больше пользователей → больше эталонов → лучше рекомендации
2. **Russian language lock-in** — нет конкурентов с native русским
3. **Domain expertise** — специфичные знания о фигурном катании (ISU rules, element definitions, biomechanics)

**Что НЕ стоит патентовать:**
- ML pipeline (быстро устареет, 18 мес на патент)
- Алгоритмы (patent → раскрытие → копирование)

**Что стоит защищать:**
- Бренд SkateLab → товарный знак (Роспатент + WIPO)
- Архитектура flow → промышленный образец (патент)
- Дизайн → авторское право
- Dataset эталонов → trade secret
