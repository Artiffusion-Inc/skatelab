# Competitive Landscape

## Direct Competitors

### 1. JudgeAI-LutzEdge

| Аспект | Детали |
|--------|--------|
| Что | 3D pose + IMU для определения ошибки лезвия |
| Технология | IMU-датчики на ботинках + 3D pose estimation |
| Статус | Исследовательский проект (4 stars на GitHub) |
| Слабость | Требует.IMU-датчики → оборудование, не масштабируется |
| Угроза | Низкая. IMU = аппаратное решение, не SaaS |

### 2. OOFSkate (MIT / NBC Sports)

| Аспект | Детали |
|--------|--------|
| Что | Body kinematics proxy features для фигурного катания |
| Технология | Single-camera видео + ML features (landing quality, GOE proxy) |
| Статус | Деплоен на Олимпиаде 2026 (NBC Sports) |
| Сильная сторона | Валидация на Олимпийском уровне, proof of concept для single-camera |
| Слабость | Нет commercial продукта, нет русского языка, нет IMU |
| Угроза | Средняя. Могут добавить consumer SaaS. |

> **Примечание:** Omega — швейцарский олимпийский хронометрист (Swatch Group), НЕ стартап-конкурент. Их система — инфраструктура судейства, не commercial продукт.

## Competitive Moats

1. **Данные:** SkatingVerse (28K клипов, 1 687 видео), Figure-Skating-Classification (5168 seq), AthletePose3D (1.3M frames) — крупнейшая коллекция датасетов фигурного катания
2. **Русский язык:** Единственный full-stack продукт с native русским → lock-in русскоязычного рынка
3. **OOFSkate approach:** Валидирован на Олимпиаде 2026 (MIT → NBC Sports) — proof of concept для single-camera видео
4. **Хореограф-планировщик:** ISU elements + CSP solver — уникальный продукт, нет аналогов
5. **Anatomical Re-ID:** Решает real-world проблему (чёрная форма на льду) — технически сложно повторить
