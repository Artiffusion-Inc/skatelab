# Hardware — Основной Продукт

> **Актуально:** Hardware-first модель. IMU-трекеры = основной продукт. SkateLab SaaS = AI-платформа.
> **Источник:** Наброски Алисы Абдуллиной (ITMO, СПб).

## Концепция

**IMU hardware** — IMU-датчики (toe + heel) на ботинках фигуриста + мобильное приложение с AI-аналитикой.

### Названия
- **IMU hardware** — hardware (IMU-трекеры)
- **SkateLab** — SaaS / AI-платформа
- История: SkateLab / AIceCoach — шуточные варианты. Ранее использовалось название EdgeSense (не актуально).

## Pain Points

| Pain | Решение IMU hardware |
|------|-------------------|
| Стоимость тренировок 15–35K ₽/мес | Объективные данные → меньше времени на разбор |
| Время разбора ошибок (1/3 тренировки) | Real-time метрики на коньках |
| Субъективность оценки ребра ±10–15° | IMU: точный угол наклона |
| Тренер-ученик конфликты | Объективные данные → нет споров |

## Business Model

**Hardware-first:** IMU-трекеры = основной продукт (15 500 ₽).
**SaaS-second:** SkateLab = дополнительная прибыль (490–990 ₽/мес).

**Unit economics:**
- VC ~5 130 ₽ (трекеры + крепление + налог УСН 15%)
- Маржа ~67% (10 370 ₽)
- Break-even математический 1.6 комплекта, реалистичный ~15/мес

## Pitch Draft (Alisa, 2026-05-06)

**Intro:** Меня зовут Алиса, я мастер спорта по фигурному катанию с 16-летним опытом. А я Михаил, занимаюсь фигурным катанием и отвечаю за техническую сторону.

**Суть:** Мы объединили любимый спорт и IT. Создали помощника для фигуристов любого уровня. Наша платформа позволяет загружать видеоролики с тренировок, анализировать их с помощью AI, давать обратную связь, фиксировать прогресс. Также используем датчики, которые крепятся на конёк. С их помощью определяем точный угол наклона конька, скорость движения, распознаём элементы, считаем обороты.

**Цель:** Сделать фигурное катание более объективным, помочь спортсменам быстрее прогрессировать, снизить финансовые издержки на тренировки.
